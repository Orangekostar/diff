# AEI figure panels

These PNG files are aspect-preserving crops of the final 300-dpi figures for manual composition. They are not part of the submission package.

Main-panel crops retain their local titles and labels. Shared color bars remain in the composed figures and are not duplicated into individual panels. Supplementary Figure S1 crops contain only the correctly proportioned scan panels; use the panel IDs in the full figure or source CSV when rebuilding labels.
