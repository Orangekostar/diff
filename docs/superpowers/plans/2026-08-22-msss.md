# MSSS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, execute, and replay the gated S1 mechanically sufficient spatial scale experiment, then execute S2 only when the validated S1 package authorizes it.

**Architecture:** Deterministic native-image scale transforms feed one immutable frozen-ResNet feature bank; a pure evaluator performs source-only nested PCA/Ridge selection and fixed-candidate outer predictions. S1 combines non-inferiority, boundary stability, and post-scale P3 spatial destruction; S2 consumes only an authorized S1 package and tests the sampling-axis MSSS on dataset, ply-count, and layup shifts.

**Tech Stack:** Python 3.13, NumPy, SciPy, PyWavelets, PyTorch/torchvision, Matplotlib, PyYAML, pytest, existing `cmc_bbdm` V3/P3/P5/multiview authorities.

---

The full workspace is not a Git repository. Generic commit checkpoints are
replaced by focused tests, diff inspection, and checksum-bound artifact replay.
