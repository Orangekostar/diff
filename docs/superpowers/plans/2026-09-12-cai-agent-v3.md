# CAI Agent v3 Controlled-Reuse Execution Plan

**Base:** `4f2b26b0f5e1593c8883b6ab78a6f7fdf700043d`

**Branch:** `research/cai-vlm-agent-v3-controlled-reuse`

**Goal:** execute the staged v3 protocol without changing legacy v2 artifacts, reopening unrelated studies, or crossing a failed scientific gate.

## Stage 1: W0 legacy rescore and mathematical contract

- Add a pure left-step error-area implementation and its policy-return adapter.
- Verify it against the supplied independent golden oracle.
- Reconstruct every v2 `(specimen, method, seed)` state trajectory from the stored CSV.
- Join the original v2 MPa authority and P0R capture provenance.
- Export state predictions, per-run corrected metrics, paired effects, old-versus-corrected comparisons, and scope deviations.

## Stage 2: W1 complete reused cohort

- Join the 276 authorized P0R image records to author-workbook `CAI_STRENGTH` MPa labels.
- Build union-find capture groups from specimen identity, original C-scan source, surface source, and repeated image identities.
- Apply the fixed per-domain capture-group hash split.
- Export the full queue, exclusions, group audit, split manifest, and label cross-checks.
- Verify the feature and VLM source bindings before any long optimization.

## Stage 3: W2 predictor gate

- Reuse compatible v2 cell embeddings and encode only missing candidates with the same frozen ResNet18 preprocessing.
- Fit the fixed constant/Ridge diagnostics.
- Train exactly the three specified neural predictor candidates within the registered update budget.
- Select `P_all` only through the predeclared VALID gate; stop Actor work if no candidate passes.
- If selected, train the three capture-group-excluded reward predictors and apply their readiness gate.

## Stage 4: W3/W4 policy pilots, only when enabled

- Adapt the existing 2-layer, 4-head, 128-wide cell Transformer to the v3 visible-state contract.
- Train seed-1 main, no-VLM, open-loop, true-static, and mean-feedback pilots.
- Apply the VALID continuation gate before additional seeds or TEST access.
- Run at most one adapted frozen-predictor GDFS pilot after predictor and policy prerequisites.

## Stage 5: Conditional evaluation and delivery

- Expand to seeds 2/3 and open the internal TEST split only when all gates pass.
- Produce only evidence supported by executed stages, with separate implementation, conformance, scientific, and engineering status.
- Run focused tests, Ruff, CLI smoke checks, scope diffs, and resource-accounting checks.
- Commit and push the isolated branch; verify local, upstream, and remote SHA equality.
