# MGMR M0 Design

Date: 2026-08-22
Status: approved by the controlling prompt and frozen before implementation

## Decision

Run only the M0 complementarity gate. Use the existing frozen ResNet18, exact
P1 internal-only baseline, P5 25% bilinear reconstruction, and a deterministic
one-level feature-domain DWT. Do not implement a graph, laminate-aware edge,
diffusion model, or learned frequency branch unless M0 passes.

The primary representation is:

```text
FULL RGB crop -> frozen ResNet18 layer3 -> db2 DWT -> GAP(cH,cV,cD)
25% P5 reconstruction -> frozen ResNet18 layer3 -> GAP
```

Every direct CAI model contains the registered metadata13 block once. Each
image-derived block is reduced by its own fold-local PCA before concatenation.
The downstream model retains the existing fold-local mean imputation,
standardization, and Ridge alpha 10 contract.

## Alternatives considered

1. Deterministic feature-domain DWT (selected). It directly tests the frozen
   coarse-plus-directional hypothesis, has no learned image encoder state, and
   makes band reconstruction and orientation auditable.
2. A WaveRNet-style learned dual-convolution frequency block. This is rejected
   for M0 because WaveRNet's `SimpleWaveletTransform` is a learned pair of 3x3
   convolution branches rather than a mathematical DWT. It would confound the
   component gate with added trainable capacity.
3. Raw RGB DWT followed by ResNet encoding. This is rejected because it repeats
   the prior raw-image wavelet intervention and does not isolate directional
   structure in the frozen representation space required by the prompt.

## Data and authority boundaries

- The cohort is the frozen 276-specimen, six-domain V3 authority.
- FULL global embeddings come from the checksum-bound existing feature bank.
- FULL and 25% layer3 maps are computed once, ordered by specimen ID, stored as
  float32, and checksum-bound.
- The 25% input uses the exact P5 endpoint-preserving digital-grid primitive.
- No target, outer-domain statistic, or outer prediction is used to construct
  image features.
- Historical exposure to all six outer domains is disclosed. M0 is a registered
  post-hoc follow-up on the frozen cohort, not an independent external test.

## Model comparison

```text
B0 = metadata13 + PCA(FULL global 512)
B1 = metadata13 + PCA(GAP(coarse layer3))
B2 = metadata13 + PCA(GAP(cH)||GAP(cV)||GAP(cD))
B3 = metadata13 + PCA(coarse block) + PCA(directional block)
B4 = metadata13 + PCA(FULL global) + PCA(directional block)
```

PCA dimensions are 8, 16, and 32. B3 and B4 select the Cartesian product of
their block dimensions by equal-domain inner LODO MAE. Ties prefer lower total
dimension, then the earlier lexicographic dimension tuple. B0 must reproduce
the registered P1 predictions and dimensions exactly.

## Strict residual audit

For each held-out outer domain, baseline residual targets on the five source
domains are generated by leaving each source domain out in turn. Each such
baseline is selected using only the remaining source domains. The directional
residual model is fitted only to these cross-fitted source residuals and then
predicts a correction for the untouched outer domain. The same procedure is
run for coarse and exact FULL baselines.

The P3 control applies the registered 8x8 patch shuffle independently at seeds
20260831, 20260901, and 20260902, then recomputes layer3 and DWT features. It
uses the same residual targets, model family, and selection code as real data.

## Gate and conditional continuation

M0 passes only when Gates A, B, and D in `docs/MGMR_M0_PROTOCOL.md` all pass.
Gate C is a strong positive diagnostic but is not mandatory. If a core gate
fails, issue `MGMR_NO_GO`, preserve all results, and stop before M1. If M0
passes, the first M1 graph will use a 7x7 Cartesian grid because specimen-level
impact-center alignment is not authoritative.

## Self-review

The design isolates the requested representation effect, retains the exact
baseline and estimator capacity, and defines every selection inside source
domains. Its main limitation is scientific rather than computational: all six
domains have been inspected in earlier phases, so a positive result cannot be
described as untouched external confirmation.
