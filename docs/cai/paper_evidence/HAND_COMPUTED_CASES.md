# 独立数值参照：不是新实验结果

## 1. 原面积定义不能改变

成本0、.125、.25，预测190、194、198，真实CAI200。

- 误差10、6、2。
- 左端阶梯面积A=(.125×10+.125×6)/.25=8，不能用梯形积分6。
- b=.0625时仍为预测190；b=.125时才是194。
- 如果末状态只有.125且预测198，那么.125至.25保持该预测，A=6。
- 没有.25以后的轨迹，查询.5必须被本轮分析范围封装拒绝。

## 2. 重复运行不是预测集成

y=200，两个repeat分别预测190和210。独立误差均值MAE=10，MSE=100，RMSE=10。不能先平均预测得到200后声称误差0。

## 3. 分组bootstrap保留组内试样权重

三件a/b/c的某指标为0/10/100。a,b属于g1；c属于g2。一次重采样g1两次、g2一次，则试样权重2/2/1，均值24。

不能把g1组均值5与g2组均值100直接按抽中组个数平均成36.667，否则改变物理试样估计量。六域等权在域内算完之后再执行；池化指标不要套域等权。

## 4. 对照也必须用它自己的最早达标点

以当前已报告的五个固定预算点为例（来源是冻结W3 absolute_cai_performance.csv，不是新轨迹结果）：

| b | 主方法MAE | GEOMETRY MAE | LEARNED_STATIC MAE |
|---:|---:|---:|---:|
| 0 | 58.550995 | 58.550995 | 58.550995 |
| .0625 | 45.517437 | 50.220895 | 46.464988 |
| .125 | 44.113567 | 46.188977 | 48.064151 |
| .1875 | 44.684544 | 46.555072 | 46.784012 |
| .25 | 44.285799 | 46.909917 | 46.993118 |

q=46.9099169921875 MPa时，在这个固定网格内，主方法最早.0625，GEOMETRY最早.125，STATIC最早.0625。
相对GEOMETRY是1-.0625/.125=50%，不是1-.0625/.25=75%；相对STATIC是0%。

这些只是主网格检查。细粒度共同断点结果必须另行从保存轨迹读取，不能用此例代替。

## 5. 非单调性和群体质量

MAE序列10/4/6/3对应预算0/.0625/.125/.25。目标q=5：第一次在.0625达到，但.125再次高于q。必须保留原曲线与反弹标记，不能把曲线变成10/4/4/3。

两试样在两个成本点的误差分别为[1,9]和[9,1]；每个共同预算的群体MAE都是5。目标q=2始终未达到，不能分别挑每件最好的成本后，报告群体MAE1。

## 6. FULL_SCAN只有一个点

FULL_SCAN在b=1时MAE41.69001007。q=42时“在已观察的完整输入流程中达到，成本1”；q=40未达到。没有证据给FULL_SCAN构造中间成本。

主方法上述五预算点均未达到q=41.69001007，应在主网格记null。更细轨迹是否曾达到需实际计算，不能提前下结论，也不能改q为44.3后称与完整扫描非劣。

## 7. 未达到和零分母

任一方法未达到目标，成本比率null；对照在b=0就达到时，比率分母0，也为null。主方法更慢得到负收益，保留负值。

## 8. 全输入索引不是排序后的行号

索引原顺序[train,vB,vA]，full_specimen_indices=[2,1]，full_predictions=[30,40]，映射为vA:30、vB:40。先按名字重排索引会错配。
