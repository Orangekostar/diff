## 2. 三种“成功”必须分开

- 代码/归档验收通过：实现和数据路径满足约定。
- 预测器/OOF准备通过：真实VALID数值达到原有资源准备条件。
- 科学或工程成功：本轮不验证Agent收益；没有工程误差限，不得宣布工程达标。

历史W2–W4失效状态不能因为新W2完成而被回写。三个候选全部失败也是可交付结果，不能改门槛让下一阶段“流程走完”。

## 3. 轻量审查输出

写 `ART/W2_REPLAY_REQUIREMENTS_REVIEW.md`，每项含：原条款、实际symbol、独立预期、命令/产物、PASS/FAIL/NOT_APPLICABLE_YET、剩余修复。只要必要检查FAIL，禁止受影响的后续训练。

有可用独立审查上下文则调用；否则如实标 `SELF_CHECK_WITH_EXTERNAL_NUMERIC_ORACLE`。不伪造审查者，不写没有执行过的命令。

- 不要求新训练重现旧43个参选时点；当前合法早停决定实际时点。
