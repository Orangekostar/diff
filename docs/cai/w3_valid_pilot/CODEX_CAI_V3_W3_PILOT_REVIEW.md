## 必须避免的五个错误判法

1. W2四固定路线平均48.517不是最佳固定路线门槛；几何分散终点46.910不是面积。
2. 反馈梯度到已测且非法位置分数，不足以证明反馈进入下一动作；看未测合法候选分数通路。但不要求每次扰动argmax必须变化。
3. Action trace里的模型调用编号如果是事后推算，应标记为重建；本轮要保存执行时真实计数。
4. 未测mask导致预测器output可变属于模型能力，不能据此宣称它一定选择有价值点位；真实VALID比较仍需单列。
5. W3的动态路线不同是正常的；固定的是样本、预测器、VLM、预算和执行规则，不能照搬W2固定前缀hash强制路径相同。

## 反馈与历史的机制检查边界

在固定已测位置与图块集合下，交换“内容—位置”对应，确认空间网络存在通往合法候选的路径。可固定current_prediction排除仅标量变化；不改正式训练，不将合成通路测试称为性能证据。

无移动成本任务不一定需要纯历史顺序，不能为验收强迫“历史一换、动作必变”。VLM初始化是否有价值由early A对照回答，不由首动作落入C0比例回答。
