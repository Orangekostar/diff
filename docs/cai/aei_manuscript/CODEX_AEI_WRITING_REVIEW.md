# AEI写作任务的有限审查提示词

你核验的是**当前六章初稿**，不是决定是否重开实验。同时读取本包主规范/蓝图、真实稿件、论文证据、必要代码与已核实文献。不能只读写作方自述的完成表。

本轮明确只要一次AEI定向内部review＋一次针对性修订后检查，不套用nature-reviewer默认三互盲报告。不构造编辑决定、审稿人履历、录用概率或假独立身份。主要科学缺口可以列Major，不得为使流程通过改为Minor；但不能擅自启动实验来处理。

## 主张检查法

对每条实质意见记录：`concern_id, paragraph_or_table, evidence_path_or_DOI, problem, minimal_fix, author_input_needed`。
不要要求concern凑数。不能从“没有找到证明”反推出真实实现一定错误。术语瑕疵与科学验证局限分开，正向结果与范围同时准确。

区分三种状态：
- `WRITING_REQUIREMENT_PASS`：对应文字/来源/材料要求已完成。
- `KNOWN_EVIDENCE_LIMIT`：例如只有selected VALID，诚实记载但不能称为新验证。
- `AUTHOR_CONFIRMATION_PENDING`：署名、基金、许可、final disclosure等。

后两种可以随完整初稿交付，不能标成科学事实已通过，也不应自动暂停全部写作。

## 独立数值检查（最多六类，无研究模型调用）

1. [0,.125,.25]、误差[10,6,2]，A=8、g=[2,0]、J=8.5。
2. 有尾段[0,.1,.2]、误差[10,6,2]，A=6.8、g=[2.4,.8]。
3. 有反弹[0,.0625,.125]、误差[10,15,5]，g=[-3.75,5]、A=8.75。
4. 四个完成时刻恰在分箱边界，分别属于对应右闭箱；c=B贡献0不被误分/丢终点。
5. 先每episode累计再repeat均值/域均值，不让RANDOM250或长轨迹得到额外权重。
6. 相同初始预测时Σ(主g−对照g)=A对照−A主；不同时保留e0差，不人为改预测使其相同。

`reference/timing_identity_reference.py`是数学基准，不是生产数值来源。真实表依保存事件生成并与原A核对，无需重算5000 bootstrap或所有W2/W3测试。

## 修订纪律

先列一份紧凑review，再改实质段落及受影响图注；无关段落保持。不能用抹去CI/改变主法/引用不存在论文来“提升positive”。

最终验收记录实际审查模式、已修内容、仍需作者决定、缺失文献/工具。如果稿已完整而格式要求未在线核实，写`DRAFT_COMPLETE_FORMAT_CHECK_PENDING`，而不是“submission-ready”。只核对原证据目录git diff与必要引用文件，不全盘hash、渗透测试或压力测试。
