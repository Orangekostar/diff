# 图表说明

共同范围：冻结selected VALID，50物理试样、48 capture groups、六域，一个学习种子面板；RANDOM有五个独立运行repeat，先算损失不集成预测。横轴采集分数是唯一原生图像像素占比的预算上限，不是设备时间。所有图保留九方法；完整输入参考使用同一MEAN_SC及既有表面输入，成本仅1.0。

**F1 — 同采集成本上限的MAE。** 599个共同事件断点上的池化MAE，精确保留阶梯和反弹，不做平滑或.25后的外推。虚线完整参考只展示成本1.0时的质量，不能理解为各预算免费获得全输入。数据：cost_error_event_curves.csv、full_scan_reference.json；主五预算点及实际采集量范围见T1。各曲线为点估计，不表示同时置信带。

**F2 — 同采集成本上限的RMSE。** 先在试样内平均repeat平方误差，再池化开方，不平均repeat RMSE。其他范围与F1相同。主方法的终点RMSE略低于均值结构，但高于无VLM反馈方法，不能由单一面积指标宣称全面优势。

**F3 — 同采集成本上限的R²。** 每个repeat在相同50件上计算R²，然后取repeat均值，不产生逐试样R²或预测集成。全输入参照仍只有成本1.0。曲线不能解释为新数据泛化确认。

**F4 — 达到相同经验群体MAE的最早预算上限。** 主结果只在既有五预算网格求最小值，目标q取完整41–61 MPa的1 MPa网格；阶梯连接仅表示该离散q网格，不给未查询的中间q精确阈值。缺点/断开表示未在观察范围达到，不填终点；full流程只有{1.0}支持集。底层MAE不单调化，本图不是部署STOP、工程合格线或非劣检验。补充599事件网格结果独立保存在equal_quality_grid.csv，不挑较有利网格替代主表。

**F5 — 四项机制面积差及探索性区间。** 正值为对照减主方法，前三完整面积/反馈面积/早期VLM面积及空间诊断按原定义；面积先试样内平均repeat，再域内平均、六域等权。线段为一次共享5000次、seed2026091401的域内capture-group重采样95%逐点区间，组的全体成员随重数加权。四区间均含0；不校正先前VALID选模与事后分析选择，不用于确认性显著/因果/新阶段门槛。

**F6 — 相对完整信息的MAE差距。** 展示部分采集MAE减同模型完整输入MAE，零线仅为两个不同成本流程的质量差为0；不是预定非劣界。全部部分方法在所记录0–.25范围未达到完整参考MAE；不补出.25–1轨迹，不声称传统方法只有全扫描才能达到某q。

**原案例图。** case_figure_reuse.csv逐项引用原W3的21张独立PNG，三案例严格为c8-16、q24-48、q16-29（完整域前缀保留于表）。每例表面+冻结VLM、真实首动作、k1/4/8/末已测图及下一实际动作、预测—成本图；不重画原图、不选新案例。灰色为未测区域；target仅为评分侧。case_same_cost_states.csv补充同预算九方法实际状态；同k只用于描述过程。
