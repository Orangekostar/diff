# 论文证据实施与图形契约

本包已给定范围、接口、估计量和验收；按用户无需询问的指令执行。主代理保留数值设计、实现和review，未委派科学决策。

- P0：paper_evidence_math.py只提供范围限定查询、repeat统计、分层group权重、加权估计、群体质量逆查询、原序full连接；8类少量合成反例先失败再实现。
- P1/P2：paper_evidence.py读取一次650最终episode；源身份只hash必要CSV/JSON/gzip/NPZ和21PNG（不读.pt/特征bank），结束核对一次。一次共享5000×50组权重，50试样保留组内权重；池化MAE与六域面积分开。全九方法共同事件断点，完整整数q范围和21锚点；full仅独立成本1。
- P3/P4：同模块只从数组生成6类单轴图：MAE/RMSE/R²成本阶梯（同预算质量）、固定网格等质量（群体经验最小成本）、4机制面积配对区间（混合方向）、全输入质量差（跨成本权衡）。不画.25→1轨迹；不平滑反弹。全部九方法保留，主方法突出但不遮蔽无VLM强对照。PNG300dpi/SVG可编辑文字，附PDF作视觉QA，字体≥7pt，约183×127mm，外置图例；单轴无需多panel对齐。原21案例PNG引用、不重画原图。
- P5：只验证新分析8类、源只读及零前向，表/MD/TeX一致，全部交付push同分支。源码不导入训练模块、不load模型，普通分析计时非硬件评测。既有数据引用不进行文献检索或投稿模板工作。

结果文字顺序：任务驱动信息获取→同成本质量→反馈机制→等质量→完整参考。VLM早期负向、无VLM整体更好、均值终点更好和域异质性必须写入；区间为selected VALID条件下事后逐点探索性，不校正选择，不作因果/工程非劣/STOP宣称。
