# 适用范围与限制

本材料是固定预测和动作的事后分析：POSTHOC_FROZEN_VALID_SINGLE_SEED。所有50件/48组曾参与checkpoint选择，且部分队列有更早研究复用历史；bootstrap不会制造独立确认集。九方法、全部不利对照及三个冻结案例保留，650 episode/10,227观测/599断点均不增加物理N。

95%区间是逐点、探索性、条件于已选checkpoint的域内capture-group bootstrap；同一5000组权重用于全部预算/对照。没有同时覆盖、多比较或选择偏差校正；四项原机制面积区间均跨零。不能用任一正向区间称确认显著或建立新gate；不做跨seed推断。

固定五预算与共同事件网格的等质量结果必须并列。目标q网格和锚点是本次新增分析约定，非原训练前注册；先共同b计算群体MAE，再求最小b，不能逐件按标签选最优停止。初次达到后可能再超q，later_recrosses_target如实报告；它不是部署STOP。比率分母0或任一未达时为NA，不外推.25以后。没有预定工程非劣界，正质量差/正部描述量不是非劣测试。

完整参考是同一个有效MEAN_SC、全64格C-scan加原有表面输入，在b=1的单点，没有轨迹面积或中间过程；不是独立验证的工业最强模型。主方法25%成本上限下MAE比完整参考高2.595789 MPa。原生像素占比不是采集时间、经济成本或探头路径代价，未评测这些工程量。

主方法比若干固定对照和开环有较低点估计，但无VLM反馈总体A与终点MAE更好。VLM先验早期方向为负，不改称收益。空间对均值A仅小幅改善，终点MAE更差、RMSE略好，非严格容量匹配。单seed方法差不能严格隔离初始化、容量和策略路径因素。

实际动作变化和测量后误差变化只有描述价值：不存在语言思维链、注意力矩阵、损伤空间GT或干预结果。离开C0不自动是纠错，无VLM首步是否在主proposal中不证明C0致因。日志的C0_RELEASED_AFTER_FIRST_ACTION可由共享规则对无VLM/static也写出；summary称recorded reason count，只有真实先前proposal收窄时才可解释为限制解除。
